# AISOP Frontend Engineering & Design Directives

All frontend engineering in this directory must strictly comply with `docs/08_Frontend/AISOP_Website_Design_Constitution.md`.

## Strict Non-Negotiable Prohibitions:
1. NEVER use purple gradients, purple-to-blue SaaS gradients, or pastel neon glow.
2. NEVER use pill-shaped buttons or excessively rounded containers.
3. NEVER use emoji icons as interface controls or section headers (use SVG icons or clean semantic badges).
4. NEVER use em dashes in user interface text or documentation copy.
5. NEVER fabricate or simulate metrics, customer counts, testimonials, or fake threat statistics.
6. NEVER use `dangerouslySetInnerHTML` or unsanitized HTML interpolation.
7. NEVER invent backend API endpoints, JSON attributes, or confidence metrics.
8. NEVER trust client-side role selection for backend authorization.
