# Public real-format samples

`otrf_flat_forwarder_excerpt.jsonl` holds 10 records, one per event type, copied **unmodified** from two public attack-simulation datasets so the ingestion path is tested on data this project did not write.

| Field | Value |
|---|---|
| Source | OTRF Security-Datasets, https://github.com/OTRF/Security-Datasets |
| Licence | MIT (per the repository's licence metadata, checked 2026-11-23) |
| Datasets | `datasets/atomic/windows/execution/host/cmd_sharpview_pcre_net.zip` and `psh_powershell_httplistener.zip` |
| Shape | One JSON object per line, flat fields from a Windows event forwarder: `Channel`, `EventID`, `Hostname`, `TimeCreated`, `UtcTime`, `Message`, plus event-specific fields |
| Event types | Sysmon 1, 3, 7, 10, 11, 13, 22 and Security 4656, 4658, 4688 (those present in the two source files; one record each) |
| Data nature | Lab-generated by the dataset authors on a simulated Active Directory environment; not customer data |
| Copy date | 2026-11-23 |

Full files (377 records) were downloaded to `D:\AISOP-Reference-Data\otrf_samples_20261123\` (outside the repository) and measured there; see `docs/10_Research/Real_Format_Ingestion_Result.md`. Credit to the Open Threat Research Forge authors.
